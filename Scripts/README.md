# 👨‍💻 Scripts — код игры на GDScript

Все скрипты `.gd` проекта (Godot 4.x). Файлы `.uid` — идентификаторы ресурсов Godot, не трогать.

## Ядро

| Скрипт | Назначение |
|---|---|
| `GameManager.gd` | **Autoload-синглтон**: данные камер (скриншоты, коды на экране, HEX-награды, сцены уровней), состояние игры, автосохранение, старт/пауза/выход |

## Терминал и камеры

| Скрипт | Назначение |
|---|---|
| `TerminalController.gd` | Логика терминала: лента логов, ввод команд, состояния (`chat`/взлом), проверка кодов, отображение собранного HEX |
| `hex_popup.gd` | Глитч-анимация окна расшифровки HEX-кода |

## Геймплей (платформенные уровни)

| Скрипт | Назначение |
|---|---|
| `game.gd` | Точка входа игровой сцены — вызывает `GameManager.start_game()` |
| `lvl_a_1.gd` | Уровень A1: подписка на сбор ключа, показ HexPopup |
| `goi.gd` | Персонаж-игрок (CharacterBody2D): движение, прыжки, коллизии, звуки шагов/прыжка/приземления |
| `key.gd` | Ключ 🔑 (Area2D): парящая анимация, частицы, сигнал `key_collected(hex_code)` |
| `camera_2d.gd` | Камера 2D с эффектом тряски (`shake`) |

## Меню и UI

| Скрипт | Назначение |
|---|---|
| `menu.gd` | Главное меню: кнопки PLAY/QUIT с wave-шейдером при наведении, музыка, SFX кнопок |
| `mini_menu.gd` | Пауз-меню: продолжить / выйти в меню / закрыть игру |
| `music_control.gd` | Ползунок громкости шины **Music** |
| `sfx_control.gd` | Ползунок громкости шины **SFX** |
