# 🎵 Assets/OST — фоновая музыка

Аудиотреки (`.ogg`), воспроизводимые через автозагрузку `GameManager` (шина **Music**, см. `default_bus_layout.tres`).

| Файл | Что играет |
|---|---|
| `level theme.ogg` | Основная тема уровней / геймплея |

Громкость регулируется ползунком из `Assets/Sprites/MusicControl` (скрипт `Scripts/music_control.gd`).

> Файлы `.import` — метаданные импорта Godot, не трогать.
