# 🖼️ Assets/Sprites — пиксельная графика

Все PNG-спрайты игры. Используются сценами из `Scenes/` и скриптами из `Scripts/`.

## Файлы в корне папки

| Файл | Назначение |
|---|---|
| `atlas.png`, `atlas_UPDATE.png` | Атласы тайлов/объектов для платформенных уровней |
| `Atlas_Player.png`, `player_an.png` | Спрайтшит и анимация игрока (GOI) |
| `ancap.png` | «Скриншот» камеры №1 — кадр наблюдения с кодом на экране (используется в `GameManager.gd`) |

## Подпапки

| Папка | Назначение |
|---|---|
| [`Main_menu/`](Main_menu/) | Фон и состояния кнопок главного меню (`PLAY`, `QUIT`: up/down) |
| [`Mini_menu/`](Mini_menu/) | Иконки пауз-меню (`resume`, `exit`: hover/default) |
| [`MusicControl/`](MusicControl/) | Иконки и ползунки настройки звука (музыка/SFX) |

> Файлы `.import` — метаданные импорта Godot, не трогать.
