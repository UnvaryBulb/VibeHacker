# 🔊 Assets/SFX — звуковые эффекты

Короткие звуки (`.ogg`), играемые через `AudioStreamPlayer` / `AudioStreamPlayer2D` на шине **SFX** (см. `default_bus_layout.tres`).

| Файл | Когда звучит |
|---|---|
| `step.ogg` | Шаги игрока в платформенных уровнях (`goi.gd`) |
| `jump.ogg` | Прыжок игрока |
| `fall.ogg` | Падение / приземление |
| `button.ogg` | Нажатия кнопок в меню и терминале |

Громкость регулируется ползунком `Scripts/sfx_control.gd`.

> Файлы `.import` — метаданные импорта Godot, не трогать.
