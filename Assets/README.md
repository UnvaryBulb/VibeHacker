# 📦 Assets — медиаресурсы игры

Здесь хранятся все медиафайлы проекта: звук, графика и шрифты. Ничего из этого не содержит логики — только ресурсы, на которые ссылаются сцены (`Scenes/`) и скрипты (`Scripts/`).

## Структура

| Папка / файл | Назначение |
|---|---|
| [`OST/`](OST/) | Фоновая музыка (треки уровня) |
| [`SFX/`](SFX/) | Звуковые эффекты (шаги, прыжок, падение, кнопки) |
| [`Sprites/`](Sprites/) | Пиксельная графика: спрайтшиты, камера-скриншоты, элементы меню |
| `PressStart2P-Regular.ttf` | Ретро-шрифт [Press Start 2P](https://fonts.google.com/specimen/Press+Start+2P), используется во всём UI и терминале |

> ⚠️ Файлы `.import` — метаданные импорта Godot. Не удаляйте и не редактируйте их вручную.
