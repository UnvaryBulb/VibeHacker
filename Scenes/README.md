# 🎬 Scenes — сцены Godot (`.tscn`)

Готовые сцены игры: экраны, уровни и всплывающие окна. Логика сцен вынесена в скрипты из `Scripts/`, ресурсы берутся из `Assets/` и `Shaders/`.

| Сцена | Назначение |
|---|---|
| `menu.tscn` | Главное меню (PLAY / QUIT), CRT-эффект поверх фона |
| `terminal.tscn` | Интерактивный терминал — принят запросы от хакера, ввод команд и кодов |
| `game.tscn` | Основная игровая сцена (переход от терминала к уровням) |
| `lvlA1.tscn` | Пиксельный платформенный уровень A1 (награда за HEX-код камеры №1) |
| `GOI.tscn` | Игрок-персонаж на платформенных уровнях (CharacterBody2D с анимацией и звуками) |
| `key.tscn` | Собираемый ключ 🔑 с частицами и сигналом `key_collected` |
| `HexPopup.tscn` | Всплывающее окно «расшифровки» HEX-кода с глитч-анимацией |
| `mini_menu.tscn` | Пауз-меню (resume / exit / quit) поверх игры |

Стартовая сцена проекта задаётся в `project.godot`; переключение сцен управляется через `GameManager` (`Scripts/GameManager.gd`).
